## 📋 Sobre o Projeto

O **Biblioteca Central** é um sistema web completo para gerenciamento e reserva de salas de estudo em bibliotecas. Com uma interface moderna e intuitiva, o sistema permite que estudantes visualizem salas disponíveis, verifiquem horários e façam reservas de forma prática e eficiente.

### ✨ Características Principais

- 🎨 **Design Moderno**: Interface dark mode com gradientes e animações suaves
- 📱 **Totalmente Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- 📅 **Calendário Interativo**: Visualize e selecione datas de forma intuitiva
- ⏰ **Gerenciamento de Horários**: Sistema inteligente de slots de tempo
- 🏢 **Múltiplas Salas**: Gerencie diferentes tipos de salas (individual, grupo, multimídia)
- ✅ **Validação em Tempo Real**: Feedback instantâneo durante o preenchimento
- 🎭 **Animações Fluidas**: Transições suaves e efeitos visuais elegantes
- 🔒 **Validação de Dados**: Sistema robusto de validação de formulários
